# VERIFY

> AI가 만든 테스트와 별개로, **내가 직접** 확인한 기록.
> 기대값은 구현 코드가 아니라 입력 데이터·합의 규칙·손 계산에서 나온다.
> 처음에 실패했다가 고친 기록도 지우지 않는다.

## 검증 원칙

| 방법 | 내용 |
|---|---|
| 작은 케이스 | 손으로 답을 아는 아주 작은 데이터를 넣어 본다 |
| 불변 조건 | 어떤 결과든 반드시 지켜야 할 규칙을 별도 쿼리·스크립트로 센다 |
| 다른 경로 재계산 | 화면·API 숫자를 DB 쿼리나 원본 파일로 따로 계산해 비교한다 |
| 일부러 깨뜨리기 | 잘못된 입력, 동시 요청, 서버 중단을 직접 만든다 |
| 테스트를 테스트 | 핵심 검사를 일부러 지웠을 때 테스트가 실패하는지 본다 |
| 화면 직접 조작 | 브라우저에서 사용자처럼 눌러 본다 |
